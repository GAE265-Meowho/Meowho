# Design System: Meowho喵戶

**Project ID:** `meowwho-v2`：首頁 UI 原型，Next.js 16 + React 19
**原始碼：** 本機 `meowhome-v2/`；GitHub `GAE265-Meowho/MeowHome` 分支 `feat/meowwho-v2-ui-prototype` 的 `prototypes/meowwho-v2/`
**線上版：** https://meowwho-v2.vercel.app
**版本：** v1.1（2026-10-29）

> 這份文件是 Meowho 前端的**大框架**，寫給人和所有 AI coding agent（Claude Code、Codex、Cursor、Gemini…）看。
> 它只規定「不能偏離的底線」和「共用的材料」：色票、字體、按鈕、間距、跨裝置規則。版面怎麼排、插畫怎麼畫、互動怎麼做，都留給你發揮（見第 1 節）。
> 數值以 `src/app/globals.css` 的 CSS 變數為準；本文件和程式碼不一致時，以程式碼為準，並在同一次修改裡更新本文件。

## 0. 硬性規則（vibe coding 時先看這段）

**必須（MUST）**

1. 顏色、圓角、陰影、間距、高度用 `globals.css` 的 CSS 變數（例：`var(--caramel)`）。需要新顏色時，先加進 `:root` 並更新第 3 節。
2. 圖示用 SVG（優先使用 `src/components/ui/Icon.tsx`，缺的就新增一個）。
3. 主要行動用 `<CatButton>`：有耳朵和鉤狀尾巴的 pill 按鈕。
4. 文字對比至少 **4.5:1**（18.66px 粗體或 24px 以上的大字至少 3:1）。
5. 可以點的東西高度至少 `var(--tap)`（桌機 36px，觸控螢幕自動變 44px）。
6. 375px 寬的手機上不能出現水平捲動。
7. 動畫要有 `prefers-reduced-motion` 的退路。
8. 照片和插畫都透過資料檔引用，保留日後換成真實照片的空間（見第 7 節）。
9. 改完跑 `npx tsc --noEmit && npm run lint`，並在 375px 和 1280px 兩種寬度實際看過畫面。

**禁止（MUST NOT）**

1. **前台不放小字備註。** 像「本月已有 36 隻貓透過 Meowho 找到家」「資料來源：農業部…」「原型示意數據」「示意資料・公開位置只到縣市＋區」「點房子看喵戶」這類說明都不要出現在畫面上。需要讓組員知道的事，寫成**程式碼註解**（見第 6 節）。
2. **前台只放最重要的資訊和按鈕。** 一個區塊只講一件事；拿不準要不要放的字，就不要放。
3. 不用 emoji 當圖示或裝飾（包含 ♀ ♂ ✨ 這類符號）。
4. 白字不放在 `--orange`（`#e8913a`）或 `--yellow`（`#f6b53b`）底上，對比不夠。
5. 不讓 AI 產生費用數字或健康診斷。費用只能來自知識庫；健康相關只寫「請帶去看醫生」。
6. 不用 Tailwind 或 CSS-in-JS。專案使用 CSS Modules（`*.module.css`）加上 `globals.css`。
7. 不改 `CatButton` 的外型（左上耳朵＋右端鉤狀尾巴＋兩條環紋），也不要加回眼睛。

## 1. 哪些是框架，哪些可以自由發揮

| 固定（照本文件） | 自由發揮（只要不違反第 0 節） |
|---|---|
| 色票與用途、對比規則 | 版面構圖、區塊排列、網格切法 |
| 字體堆疊、字級下限 | 標題文案、插畫內容與構圖 |
| `CatButton` 外型、`Icon` 的畫法 | 新的互動、動畫、捲動效果、3D 或地圖等表現方式 |
| 間距單位、斷點、觸控高度 | 新元件，但要沿用本文件的色票、圓角和陰影語言 |
| 命名（第 10 節） | 卡片和面板的內部排版 |

做新嘗試時，問自己一句：**「看起來還是同一個溫暖、平面、乾淨的保護貓網站嗎？」** 是的話就放手做。

## 2. Visual Theme & Atmosphere

**溫暖、平面、乾淨，像一本手作繪本的保護貓網站。**

- **氣氛：** 午後陽光照進中途貓屋。用奶油色紙張當底，配黃橘色塊，不走科技感、玻璃擬態或霓虹色。
- **參考：** 日本保護貓網站「ほごねこクリニック」（黃橘色帶、貓耳形的區塊上緣、有機形狀的照片框）和「保護猫カフェ285」（大圓角色塊、溫柔的留白）。
- **密度：** 中等偏鬆，留白要大方。資訊少而清楚，比資訊多而完整更重要。
- **貓的語彙：** 貓耳形邊緣（`EarTop`）、波浪分隔（`Wave`）、貓形按鈕、肉球圖示、紙質斑點背景。可以自由延伸新的貓元素。
- **語氣：** 像中途愛媽在跟你聊天，溫柔、具體、講真實的日常，不推銷。

## 4. Typography Rules

- **字體堆疊**（`--font-body`）：`Quicksand`（英數）→ `Zen Maru Gothic`（日系圓體）→ `Noto Sans TC`（繁中），用 `next/font/google` 載入。
- **字重：** 標題、按鈕、標籤用 700；內文用 400 到 500。
- **數字：** 大數字用 `var(--font-quicksand)`，比較圓、比較可愛。
- **字距：** 中文標題加 `letter-spacing: 0.04–0.08em`。
- **斷行：** 標題把語意片段包成 `<span>`，CSS 設 `display: inline-block`，避免詞從中間斷開。

| 層級 | 建議大小 | 行高 |
|---|---|---|
| 頁面主標 h1 | `clamp(36px, 5.4vw, 64px)` | 1.2 |
| 區塊標題 h2 | `clamp(26px, 3.2vw, 38px)` | 1.4 |
| 卡片標題 h3 | 19–22px | 1.45 |
| 內文 | 16px（手機 14–15px） | 1.6–2.0 |
| 次要文字 | 13–14.5px | 1.7 |
| **下限** | **12px** | 不可再小 |

字級可以依版面調整，但要守住下限和層級關係：同一畫面裡，h2 永遠比 h3 大。

## 5. Component Stylings

共用元件在 `src/components/ui/`，優先重用。

- **按鈕 `CatButton`：**
  - 外型是完整 pill：左上兩隻圓角貓耳，右端伸出一條往下彎成鉤狀的粗尾巴，尾端有兩條淺色環紋。
  - **Primary：** `--caramel` 底配白字，下方 6px 的 `--caramel-deep` 平面陰影。
  - **Ghost：** 白底、`--orange` 外框、`--orange-deep` 字。
  - **尺寸：** `sm`、`md`、`lg`。
  - **互動：** hover 時上移 2px、尾巴搖、耳朵抖。
  - 按鈕會自己留出耳朵和尾巴需要的空間。
- **卡片與面板：** 白底，圓角 28 到 36px，用**平面偏移陰影** `0 6px 0 -1px var(--line)`，像紙片疊在桌上。只有浮起來的面板才用 `--shadow` 這種柔和的暖色模糊陰影。
- **Pill 與標籤：**
  - 功能名稱的 kicker：`--yellow` 底配 `--ink` 字，加 16px 圖示。共用元件是 `home/SectionHead.tsx`。
  - 篩選 chip：選中時用 `--ink` 底配 `--yellow` 字。
- **輸入框：** 白底 pill，`--line` 外框，聚焦時外框變 `--orange`，placeholder 字色用 `#8f7663`。每個輸入都要有 `<label>` 或 `aria-label`。
- **圖示 `Icon`：** 24×24、單一 `currentColor` 填色、用 even-odd 挖空。純裝飾時加 `aria-hidden`。
- **區塊邊緣 `Edges`：** `<EarTop>`（貓耳頂）、`<Wave>`（波浪）。
- **照片：** 用有機形狀直接裁切（不規則的 `border-radius` 或 SVG `mask`），**不要外加白框**。

## 6. 畫面要乾淨：備註寫在程式碼裡

前台只留使用者「需要知道、需要按」的東西。其他資訊依下表處理：

| 這類資訊 | 放哪裡 |
|---|---|
| 資料來源、統計出處 | 該段文字上方的 JSX 註解 `{/* 數據出處：… */}` |
| 「這是示意資料」「之後要串接 API」 | 資料檔或元件上方的註解，例如 `// Demo data — replace with …` |
| 業務規則（例：喵戶長可要求必做虛擬飼養） | 用到這條規則的元件旁邊的註解 |
| 隱私或安全限制（例：位置只公開到縣市＋區） | 資料檔或元件的註解 |
| 照片授權 | `src/lib/photos.ts` 裡每張照片的 `page` 欄位 |
| 操作提示（例：「點房子看喵戶」） | 優先讓介面自己說明（hover 狀態、圖示、空狀態文案），不要另外加小字 |

**寫給組員的註解範例：**

```tsx
{/* 數據出處（不顯示在前台）：農業部 114 年家犬貓飼養調查。引用前請以最新公告為準。 */}
<p className={styles.lead}>台灣家貓已有 174 萬隻…</p>
```

## 7. 影像與素材：保留替換空間

目前的照片是 Unsplash 的免費照片，之後會換成合作中途授權的真實貓照片。為了讓替換時只要改資料、不用動版面：

1. **集中登記：** 每張照片都登記在 `src/lib/photos.ts`（`src`、`alt`、`page`），元件只用 `photos.xxx` 或資料裡的 `cat.photo`，**不要在元件裡直接寫圖片網址**。
2. **固定框、彈性圖：** 圖片放在有固定比例的容器裡（`aspect-ratio`，例如 4/3 或 5/4），搭配 `next/image fill` 和 `object-fit: cover`。不管換上什麼尺寸的照片，版面都不會跳動。需要調整焦點時用 `object-position`。
3. **沒照片也不能空白：** 容器底色用 `--yellow-soft`；資料沒有照片時，顯示平面的貓剪影插畫，不留空框。
4. **外部圖片來源：** 新的圖片網域要加到 `next.config.ts` 的 `images.remotePatterns`。如果改用 Supabase Storage，同樣在這裡加入。
5. **授權：** 免費素材只用 Unsplash License（不能用 Unsplash+）；真實照片要有中途或飼主的授權。`alt` 寫中文描述。

## 8. Layout Principles

- **容器：** `.wrap` 最大寬 1180px（`--wrap`），左右留白 16px（`--gutter`）。
- **斷點：**
  - `≤ 767px` 手機：header 高 56px，底部固定分頁列 68px（`--tabbar-h`），`body` 會自動預留底部空間。
  - `768–1023px` 平板：多欄改成單欄或雙欄。header 的選單文字一律不換行（≤ 1100px 收起 Logo 副標、縮小間距；≤ 900px 登入按鈕只顯示「登入」）。
  - `≥ 1024px` 桌機：header 高 68px，主選單顯示在 header。
- **區塊節奏：** 大區塊之間留 88 到 120px；色帶區塊可以用 `EarTop` 接、`Wave` 收尾。
- **網格：** 建議桌機 3 欄、平板 2 欄、手機 1 欄。橫向捲動的列要加 `scroll-snap`，並在自己的框內捲動。
- **固定元素：** 手機上任何固定在畫面底部的東西都要避開分頁列，並考慮 `env(safe-area-inset-bottom)`。

## 9. 跨裝置易讀與易用（Checklist）

- [ ] 內文對比 ≥ 4.5:1，大標 ≥ 3:1。白字只放在 `--caramel`、`--caramel-deep`、`--ink` 底上。
- [ ] 沒有小於 12px 的字；手機內文 ≥ 14px。
- [ ] 可點目標高度 ≥ `var(--tap)`，相鄰目標至少間隔 6px。
- [ ] 所有互動都能用鍵盤操作，並顯示 `:focus-visible` 外框（已全域設定）。
- [ ] 375px 寬時沒有水平捲動。
- [ ] 一頁一個 `h1`；區塊用 `<section aria-labelledby>`；會即時更新的區域加 `aria-live="polite"`。
- [ ] 開啟「減少動態效果」時，頁面仍然可以完整使用。
- [ ] 畫面上沒有小字備註（第 0 節禁止第 1 條）。

## 10. 命名（以 `MeowWho_專題規劃_1030.pptx` 為準）

- **品牌：** Meowho喵戶。標語：「讓每一隻貓從中途到新家立足，支撐最重要的一段路。」
- **功能：** 喵戶建檔處、時光小屋、帶我回家領養站、3D 養貓中心、7 天虛擬飼養（不要寫成「虛擬試養」）、AR 環境報告站、貓咪諮詢站
- **角色：** 喵戶長、領養人。領養完成叫「移轉」。
- **導覽列：** 帶我回家／AR 環境報告／7 天虛擬飼養／時光小屋／貓咪諮詢站
- **手機分頁：** 首頁／帶我回家／建立喵戶／時光小屋／我的喵戶

## 11. Do / Don't 速查

| Do | Don't |
|---|---|
| `<Icon name="heart" />` | 用 emoji |
| `<CatButton href="…">` | 自己刻一顆橘色按鈕 |
| `background: var(--caramel); color: #fff` | 白字放在 `--orange`、`--yellow` 底上 |
| 平面偏移陰影 `0 6px 0 -1px var(--line)` | 又黑又重的模糊陰影 |
| 照片登記在 `photos.ts`，放進固定比例的容器 | 在元件裡寫死圖片網址 |
| 備註寫成程式碼註解 | 畫面上出現「資料來源：…」「示意資料」小字 |
| 一個區塊一個重點、一個主要按鈕 | 把所有資訊都塞進畫面 |
