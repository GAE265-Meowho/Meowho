## 目前狀態
首頁「喵喵諮詢站」為固定問答示意，數字標示為示意。

2026-11-04（#186）：後台 `/MeowHQ/assets?tab=food` 建立皇家貓用商品目錄。來源是台灣官方 sitemap，共 86 款；48 乾糧、36 濕糧、1 營養液、1 奶粉。照片縮至最長邊 768px，放 `public/hq-food/royalcanin/`，不使用通路圖片或熱連結。分類沿用官方基本資料（含絕育 boolean），多選同組 OR、跨組 AND。

商品資料在 `src/lib/hq/food/products.json`；通路參考價人工登錄在 `prices.json`，目前 72 款有價，14 款待查價。價格與包裝一一對應，營養液整組價格明確標示為單瓶價格乘三的估算。官方頁面無電商報價的 0 不匯入。`catalog.ts` 提供穩定商品 ID、篩選與未來購買前置條件；尚無錢包、購買 API、訂單或餵食庫存，也未寫入 Supabase。

詳細資訊只存 `officialUrl` 並開新分頁到官方頁，未保存成分、營養資訊、宣稱及餵食指南。商品頁回應只在匯入程式記憶體中讀取，輸出採欄位白名單。

## 地雷
- 處方飼料只在有獸醫診斷紀錄時顯示，固定附提示。
- #186 後台是管理員素材目錄，可檢視全部獸醫配方；前台虛擬商店須從伺服器以商品 ID 重新查價、驗證診斷紀錄，未查價不可免費購買。`canVirtuallyBuy` 是共用前置條件，不代表已實作購買授權或錢包。
- 商品圖片公開可讀不等於已獲永久轉授權；保留官方圖片來源，競賽外用途需另確認適用權限。
