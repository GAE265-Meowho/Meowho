## 面試官追問時的備用回答（正式發表不主動說）

**為什麼擷取最多八張畫面？** 避免把整部影片每一格都送進模型，控制分析量並保留代表性的環境證據。

**如何降低 AI 誤判？** 以結構化輸出、資料驗證和來源影格追溯，區分畫面事實與待現場確認的風險；這些措施不能保證模型永不誤判。

**AI 改善圖片是真實施工結果嗎？** 不是，屬於模擬示意；圖片中的區域標示也不等同人工標註驗證的物件偵測精度。

**為什麼需要背景 Worker？** 分析可能耗時數分鐘，由 PostgreSQL Queue 和 Docker Worker 非同步執行，使用者不用一直留在網頁等待。

**效能有實測嗎？** 固定六件 Image Edit 的受控實驗，兩路並行使改圖階段中位數 185.154 秒縮短到 101.207 秒，約減少 45.34%；不是整套系統加速率。
