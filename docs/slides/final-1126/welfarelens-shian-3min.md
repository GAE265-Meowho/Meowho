# AI 居家安全檢測｜11/26 兩分鐘定版（前導 → 真實 Demo → 技術總結）

> 企業面試官版。第一頁介紹問題，真實網站展示成果，第二頁只講三項工程決策。個人 HTML 沿用舊檔名以保留連結。

## 第一頁｜產品前導（約 40 秒）

大家好，我是世安。使用者上傳居家影片之後，系統除了前面介紹的 3D 建模，也會產生 AI 居家安全檢測報告，這就是我負責的模組。

想領養貓咪的飼主，可能準備了貓砂盆、飼料，卻忽略家裡本身可能有風險。像是電線可能被啃咬、窗戶缺少防護、窗簾繩子可能纏繞，或是對貓有毒的植物。

我們希望透過 AI 幫飼主找出這些容易忽略的問題，並提供具體的改善建議。

## 真實網站 Demo（約 45 秒）

**〔切換到預先開好的真實安全報告，展開一個風險項目〕**

在報告上，我們把優先改善的風險放在前面。像這個案例，左邊是原始影格，右邊是 AI 產生的改善示意，並提供具體的建議。下方可以展開完整報告，也有 PDF 下載選項。

## 第二頁｜簡單技術總結（約 30–35 秒）

剛剛看到的是我們實際做出來的產品。技術上，我們主要解決三個問題。

第一，讓 AI 找到的風險有原始照片和時間可以確認。

第二，因為 AI 分析需要好幾分鐘，所以我們讓背景系統處理，網站不用一直等待同一個請求。

第三，我們也優化了改善圖片的生成效率。在固定六件的受控測試中，整批改圖耗時從約 185 秒降到 101 秒，減少大約 45%。

最後，風險資訊會整理成資料，供後續模擬飼養模組使用。

## 備用追問（上台不主動講）

- **照片怎麼對應？** FFmpeg 選最多八張代表影格，保留時間與 SHA-256，並用 JSON Schema、Zod 檢查模型輸出格式。格式正確不等於模型判斷正確。
- **背景如何處理？** PostgreSQL Scoped Queue 與 Docker Worker，透過 Lease／Attempt 控制領件與完成。正式站已完成單筆驗收，尚未驗證長期常駐與大量並行。
- **45% 代表什麼？** 固定六件改圖的受控實驗：單路中位數 185.154 秒、雙路 101.207 秒（−45.34%）；不是完整系統加速。
