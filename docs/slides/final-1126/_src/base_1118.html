03軟體架構設計04 / 10

軟體架構：AI 只透過一層進來，邏輯都能測試

畫面與 API

Next.js App Router：前台、MeowHQ 後台、/api/*

商業邏輯

src/lib/ 純函式＋單元測試：配對、劇情、花費公式、權限

AI 層

src/lib/ai/：LangChain，可切換 Azure OpenAI、OpenAI、Gemini；業務程式不能直接呼叫供應商

提示詞與防護

提示詞集中在 src/lib/prompts/；使用者的話一律包成資料、限制字數

儲存層

src/lib/storage/＋Supabase；資料庫只存路徑，不存檔案

五個 AI 模組：輸入 → 輸出
模組輸入輸出
幫我找貓一句話＋喵戶資料＋貓的介紹條件、排序後的貓、推薦理由
類本尊 3D 貓中途上傳的 1～3 張照片三視角圖 → 貼圖 → 3D 貓模型
我的 3D 房間一支居家影片3D 房間、家具清單（scene.json）

領養任務與報告任務中的選擇＋安全報告五年後意外劇情、試養報告

規則：花費、年齡等數字只來自資料或公式，AI 不產生數字。

04系統架構設計05 / 10

系統架構：網站即時回應，重的 AI 工作交給 worker

資料怎麼流動
前台手機／電腦，Next.js PWA
網站 APIVercel：呼叫 AI、簽短效上傳網址
雲端 AI 服務Azure OpenAI、Gemini、Embedding、AI 影像編輯
Azure Blob私有 media-dev：居家影片、安全檢測報告
Supabase登入、資料庫＋pgvector、工作佇列、通知、私有 Storage（3D 房間、3D 貓、照片、音效）
背景 AI worker：從工作佇列領工作 → 讀影片或照片 → 成果寫回、通知使用者
3D 房間COLMAP、Brush、Grounding DINO、SAM 2
3D 貓貼圖Hunyuan3D-Paint（GPU）
居家安全檢測Azure VM：FFmpeg 抽影格 → Azure OpenAI 判讀 → AI 影像編輯 After
部署與資料保護
  • 正式站：Vercel 部署 main，每個 PR 自動產生預覽站
  • 權限：每張資料表都開 RLS，前端只拿 anon key
  • 上傳：影片直傳 Azure，網址短效、只能寫指定路徑
  • 隱私：3D 房間與完整報告只有本人看得到；給中途的試養報告不含家裡位置與裁切照
  • 影片：3D 與安全檢測都完成後由清理程式刪除
05Code Review06 / 10

Code Review：AI 失敗有備案，報告接進劇情，流程有守門

① 幫我找貓（RAG 排序）
src/app/api/find/route.ts
// AI 讀不懂就改用關鍵字規則 parsed = (await parseFindQuery(q)) ?? keywordConditions(q); // 那句話優先，喵戶資料補空缺 merged = mergeConditions(parsed, home); // 介紹沒變就沿用存好的向量 if (s.content_hash === textHash(text)) vectors.set(cat.id, s.embedding); // 算不出來就整批改用備案 else queryVec = null;
  • 先用規則排除，再依意思相近排序
  • 向量用內容雜湊快取，省 API 費用
  • 只用公開資料，私密日記不進配對
② 領養任務：安全報告 → 五年後意外
src/lib/play/year5-hazard.ts
// 用這一輪開始時定格的報告 // 續玩也一樣，不讀最新那份 if (demo || !signedIn || !runReportId) return null; // 只接受本站同源的裁切照路由 return url === want ? url : null; // 示範報告、沒照片都不跳彈窗 return Boolean(item && !item.demo && item.cropUrl);

  • 裁切照每次重新授權，不外流網址
