# MeowHQ｜喵星總部 — 單元功能測試計畫（Unit Test Plan）

> v0.1｜2026/10/28｜對應《MeowHQ 後台管理規格書》v0.1、《MeowHQ 開發計畫》任務編號 T-HQ-*、SRS v1.1 M15
> 沿用《03_單元功能測試計畫》的工具、通過標準與格式；本文件只列 MeowHQ 的案例。

## 1. 範圍
- 權限判斷、處置規則、待辦彙總、網址與登入閘門、列表狀態、通知對象：以 `src/lib/hq/` 純函式測試（Vitest）。
- 互動元件：Vitest＋Testing Library（jsdom）。
- 資料庫函式與 RLS：Supabase 本機＋SQL 測試腳本（UT-HQDB）。
- 不測：真實 Google 登入、3D 檔實際渲染（留給模組測試與 E2E）。

## 2. 通過標準
- 全部案例通過才能合併。
- `src/lib/hq/` 權限與處置邏輯行數覆蓋率 ≥ 90%（比全專案 80% 更嚴，因為是安全邊界）。
- 先寫測試再實作（AGENTS.md §6）：每個 T-HQ 任務的 PR 必須先包含對應的失敗測試。

## 3. 測試資料（固定角色）

| 代號 | 身分 | 模組授權 |
|---|---|---|
| SA1、SA2 | 系統管理員 | 全部 |
