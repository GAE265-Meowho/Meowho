# Meow Home 貓戶｜端對端測試計畫（End-to-End Test Plan）

> v1.0｜2026/10/28｜以真實使用者旅程驗證整個系統，同時作為 11/26 Demo 腳本的基礎

## 1. 目標
- 驗證四種角色的完整旅程在**手機瀏覽器**上可以順利完成。
- 驗證 AI 功能在真實資料下的品質與速度。
- 產出 Demo 的穩定腳本。

## 2. 環境與裝置

| 項目 | 內容 |
|---|---|
| 環境 | Production 前的 staging（與正式環境同設定） |
| 裝置 | iPhone（Safari）×1、Android（Chrome）×1、桌機 Chrome ×1 |
| 網路 | Wi-Fi、4G 各一輪 |
| 帳號 | 貓戶長（中途）、貓戶長（一般飼主）、領養人（新手）、領養人（有經驗）、管理員 |
| 自動化 | Playwright（行動裝置模擬）執行 E2E-01～05；AR 與語音以人工測試 |
| 時程 | 11/23 第一輪、11/24 回歸＋Demo 彩排 |

## 3. 通過標準
- 所有 E2E 情境在 iPhone 與 Android 都能完成（AR 3D 除外，iOS 驗證降級）。
- 無 Blocker／Critical 缺陷。
- 效能：首頁 < 2.5 秒、RAG 搜尋 < 5 秒、照片描述 < 15 秒。
- AI 品質：RAG 前 3 名相關度 ≥ 70%；週報人工評分 ≥ 4／5；費用數字 100% 與資料庫一致。

## 4. 端對端情境

### E2E-01｜中途建立貓戶並送養準備
1. 手機開啟首頁 → Google 登入 → 同意條款 → 選「我有養貓」
2. 建立貓戶「小橘之家」（台中市北屯區）
3. 拍照新增貓「橘子」→ 確認 AI 建議 → 對話問答 → 語音自由口述 → 確認寫入
4. 寫 3 篇日記（1 篇私密、2 篇公開含照片），上傳 1 支 45 秒影片
5. 新增獸醫診斷「泌尿道」
6. 設為待領養：領養費 0 元＋結紮疫苗 1,500 元；流程勾選「面談＋7 天虛擬飼養」
7. 管理員觸發週報

**驗證點**：名片與資料一致；影片摘要完成通知；週報含影片內容；貓出現在首頁「帶我回家」；處方飼料＋提示出現；私密日記不在動態牆。

### E2E-02｜訪客找貓
1. 未登入開啟首頁 → 看統計數字與帶我回家
2. 搜尋列輸入「我住台中北屯，第一次養，想要親人的成貓」
3. 查看結果與推薦理由 → 切換全台 → 點進「橘子」
4. 查看週報、領養流程、適合飼料 → 點「私訊」

**驗證點**：條件解析正確；橘子在前 3 名；點私訊時導向登入，登入後回到橘子頁。

### E2E-03｜新手領養人完整領養（核心 Demo）
1. 登入 → 選「我想領養」→ 領養人 onboarding（語音＋文字）
2. 帶我回家依配對排序 → 進入橘子頁 → 私訊中途（選「詢問領養」）
3. 嘗試申請 → 系統提示需完成準備度評估
4. 上傳居家環境影片 → 取得報告 → 勾選已改善項目
5. 開始橘子的 7 天虛擬飼養（加速模式）→ 完成 7 天任務 → 取得徽章與摘要
6. 提出領養：閱讀須知與首年花費 → 點擊新手領養包產品 → 勾選已閱讀 → 送出
7. 中途：申請管理 → 查看比較表 → 推進「面談」→「虛擬」自動完成 → 核准
8. 雙方確認移轉 → 領養人自動建立貓戶 → 加速試養 14 天 → 完成

**驗證點**：每步驟都有站內通知；申請單帶入報告、徽章、摘要；首年花費數字＝公式；導購點擊記錄含 UTM；移轉後時間軸分段、中途唯讀可追蹤；居家影片原檔刪除；首頁成功媒合 +1。

### E2E-04｜多人申請與婉拒
1. 3 位領養人申請同一隻貓（其中 1 位有經驗、直接申請）
2. 中途婉拒 1 位（附原因）、核准 1 位
3. 第 4 位領養人已有 3 件申請中，嘗試第 4 件

**驗證點**：被婉拒者收到通知；其餘自動「已由他人領養」並收到相似貓推薦；第 4 件被阻擋。

### E2E-05｜社群互動與分享
1. 會員追蹤小橘之家 → 動態牆看到其公開日記
2. 按讚、留言 → 分享連結到 LINE
3. 檢舉一則不當留言 → 管理員下架

**驗證點**：通知正確；LINE 預覽正確；下架後不再顯示。

### E2E-06｜管理員維運
1. 匯入爬取的皇家產品 → 審核 → 發布
2. 更新 2 筆參考價
3. 修改知識庫文章 → 發布
4. 查看導購成效儀表板

**驗證點**：未審核產品不顯示；首年花費使用新價格；知識區更新；儀表板數字與 product_events 一致。

### E2E-07｜內容審核與隱私
1. 上傳非貓圖片 → 確認未公開
2. 發布「品種貓一隻 8000 元」日記 → 確認被標記
3. 訪客嘗試直接存取私密貓網址、他人申請單網址

**驗證點**：審核攔截；私密資源 404／403。

### E2E-08｜AR 環境體驗（人工，P3）
1. Android Chrome：開啟 AR 模式 → 放置 3D 貓 → 走到風險點
2. iPhone Safari：確認降級為 3D 模型檢視與影片報告

**驗證點**：Android 可放置；iOS 不會空白，有替代流程。
