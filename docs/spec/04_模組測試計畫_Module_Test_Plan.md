# Meow Home 貓戶｜模組測試計畫（Module / Integration Test Plan）

> v1.0｜2026/10/28｜驗證單一模組內各元件（UI＋API＋資料庫＋AI）串接，以及模組之間的介面

## 1. 範圍與方法

| 項目 | 內容 |
|---|---|
| 環境 | Staging（Vercel preview＋Supabase staging＋Cloud Run staging） |
| 資料 | 種子資料（10–20 隻貓、5 位領養人、2 位貓戶長、1 位管理員） |
| AI | 使用真實 API，但限定測試集與次數；記錄 ai_logs 檢查成本與延遲 |
| 工具 | Playwright（API＋UI）、Postman／Bruno（API 集合）、SQL 檢查腳本 |
| 時程 | P1 模組：11/10–11/12；P2 模組：11/20–11/22 |
| 進入條件 | 該模組單元測試全數通過、部署到 staging |
| 結束條件 | Must 案例 100% 通過；Should 案例 ≥ 90%；無 Blocker／Critical 缺陷 |

## 2. 缺陷分級

| 等級 | 定義 | 處理 |
|---|---|---|
| Blocker | 核心流程無法進行（登入、建檔、申請、移轉） | 當天修 |
| Critical | 資料錯誤、權限外洩、隱私資料外露 | 24 小時內 |
| Major | 功能錯誤但有替代操作 | 下個檢查點前 |
| Minor | 版面、文字 | 收尾前 |

## 3. 模組測試案例

格式：`MT-模組-流水號`

### M01 帳號與權限
| ID | 情境 | 步驟 | 預期 |
|---|---|---|---|
| MT-01-01 | 首次登入 | Google 登入 → 條款頁 → 同意 → 分流頁 | 寫入 users、terms_agreed_at；導向分流頁 |
| MT-01-02 | 拒絕條款 | 不勾選同意 | 無法進入任何需登入頁面 |
| MT-01-03 | 管理員 | 白名單帳號登入 → /admin | 可進入；一般帳號 403 |

### M02＋M03 貓咪建檔
| ID | 情境 | 步驟 | 預期 |
|---|---|---|---|
| MT-02-01 | 拍照建檔 | 上傳照片 → 確認 AI 建議 → 對話 5 題 → 完成 | 貓咪資料正確寫入；名片與資料庫一致 |
| MT-02-02 | 自由口述 | 語音口述一段 → 查看 diff → 確認 | 只有確認的欄位寫入 |
| MT-02-03 | 最少欄位 | 只填名字、性別、照片 | 建立成功；其他欄位顯示「之後再補」 |
| MT-02-04 | 設為待領養 | 填領養費＋勾選流程 → 儲存 | 狀態待領養、強制公開、出現在帶我回家 |
| MT-02-05 | 獸醫診斷 | 新增「泌尿道」診斷 | 貓咪頁顯示對應處方飼料＋提示 |
| MT-03-01 | 領養人 onboarding | 文字＋語音混合完成全部問題 | adopter_profiles 寫入、向量產生 |

### M04＋M05 時光小屋與 AI 多媒體
| ID | 情境 | 步驟 | 預期 |
|---|---|---|---|
| MT-04-01 | 公開日記 | 寫日記（2 張照片、標記 2 隻貓、公開） | 出現在兩隻貓時間軸與動態牆 |
| MT-05-01 | 照片描述 | 上傳照片 | 15 秒內 media_analyses 有描述與標籤 |
| MT-05-02 | 影片摘要 | 上傳 45 秒影片 | 背景處理完成後通知；有影格描述＋逐字稿 |
| MT-05-03 | 週報 | 手動觸發週報排程 | 每隻有紀錄的貓產生週報；寫入向量 |
| MT-05-04 | 週報失敗重跑 | 模擬 LLM 逾時 | ai_logs 記錄錯誤；重跑成功且不重複產生 |

### M06 動態牆
| ID | 情境 | 步驟 | 預期 |
|---|---|---|---|
| MT-06-01 | 社群互動 | 追蹤貓戶 → 按讚 → 留言 | 計數正確；貓戶長收到通知 |
| MT-06-02 | 外部分享 | 複製公開日記連結貼到 LINE | 顯示照片與標題預覽 |
| MT-06-03 | 檢舉 | 檢舉一則留言 | 後台檢舉區出現 |

### M07 AI 配對
| ID | 情境 | 步驟 | 預期 |
|---|---|---|---|
| MT-07-01 | 訪客一句話 | 輸入 10 句測試需求 | 5 秒內回應；人工評估前 3 名相關度 ≥ 70% |
| MT-07-02 | 範圍切換 | 同縣市 → 全台 | 結果數增加；同縣市結果仍優先 |
| MT-07-03 | 會員配對 | 完成 onboarding 後進入帶我回家 | 依配對分數排序並顯示原因 |
| MT-07-04 | 私密不外洩 | 私密日記含特殊關鍵字，以該字搜尋 | 不因私密內容命中 |

### M08 準備度評估
| ID | 情境 | 步驟 | 預期 |
|---|---|---|---|
| MT-08-01 | 環境報告 | 上傳 30 秒居家影片 | 產出風險清單與建議；使用者可勾選確認 |
| MT-08-02 | 虛擬飼養（加速） | 開啟加速 → 跑完 7 天 | 每天 2–3 任務；第 7 天產出摘要與徽章 |
| MT-08-03 | 虛擬貓生成 | 以 3 隻不同毛色的貓生成 | 人工評估外觀相似（毛色、花紋） |
| MT-08-04 | 情境貼近本尊 | 貓日記有「怕吸塵器」 | 7 天內至少 1 個相關任務 |

### M09 領養流程（跨 M02、M08、M10、M11）
| ID | 情境 | 步驟 | 預期 |
|---|---|---|---|
| MT-09-01 | 申請送出 | 讀須知與花費 → 勾選 → 送出 | 申請單自動帶入資料正確；無姓名電話欄位 |
| MT-09-02 | 依設定的步驟 | 貓設定面談＋虛擬 | 申請人看到對應步驟；貓戶長逐步推進 |
| MT-09-03 | 多人申請 | 3 人申請 → 核准 1 人 | 其餘 2 人狀態更新並收到通知 |
| MT-09-04 | 移轉 | 雙方確認 | 貓移到新貓戶；時間軸分段；原貓戶唯讀；紀念卡 |
| MT-09-05 | 隱私刪除 | 移轉完成 | 居家影片原檔刪除，報告保留 |
| MT-09-06 | 試養完成 | 加速時間 14 天 | 狀態完成；首頁成功媒合 +1 |
