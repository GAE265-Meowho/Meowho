# Meow Home 貓戶｜單元功能測試計畫（Unit Test Plan）

> v1.0｜2026/10/28｜對應《01_系統需求規格書》《02_開發任務清單》

## 1. 目的與範圍
驗證每個函式、API handler、資料轉換與 LLM 輸出解析，在隔離環境下行為正確。不呼叫真實外部 AI（以 mock／錄製回應取代）。

## 2. 工具與環境

| 層 | 工具 |
|---|---|
| Next.js（TypeScript） | Vitest＋Testing Library；MSW mock 外部 API |
| Python AI Worker | pytest＋pytest-mock；ffmpeg 使用 5 秒測試影片 |
| 資料庫函式／RLS | Supabase 本機（supabase start）＋pgTAP 或 SQL 測試腳本 |
| LLM 輸出 | 固定測試集（golden files）＋JSON Schema 驗證 |
| CI | GitHub Actions：每次 PR 執行 lint＋unit test |

## 3. 通過標準
- 所有單元測試通過才能合併 PR。
- 核心邏輯（推導、計算、狀態機、權限）行數覆蓋率 ≥ 80%；其餘 ≥ 60%。
- 每個 Must 需求至少有 1 個單元測試。
