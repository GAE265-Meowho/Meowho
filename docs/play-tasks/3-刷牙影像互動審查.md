# #356 擬真刷牙互動審查

以下是程式與現有素材審查。瀏覽器連線逾時，尚無前後操作截圖與實際畫面驗收。

| 問題 | 觀察證據 | 使用者影響 | 可能原因 | 改善優先級 |
|---|---|---|---|---|
| 翻唇跳階 | 原版在 .012、.04 直接換圖 | 拖動距離與視覺不同步 | 圖層以 hidden 切換 | 高 |
| 空白鍵瞬間露牙 | 原版按下後直接送入 .04 | 難以看清翻唇動作 | 鍵盤沒有過渡 | 高 |
| 滑鼠角色不清楚 | 原版只有被捕捉的指標能移動刷具 | 玩家容易以為空白鍵失效 | 指標一律以按下分配角色 | 高 |
| 刷具與命中回饋不明 | 原版角度固定，靜止仍顯示命中 | 不易辨識是否正有效清潔 | 工具外觀與回饋未反映刷動 | 高 |
| 嘴部可能疊影 | 三張同尺寸素材的唇緣、牙齒位置各自不同 | 過渡可能同時看見兩個輪廓 | 獨立生成的影像不是同一動作序列 | 待瀏覽器檢查 |

| 方案 | 畫面與操控 | 行動成本與維護 |
|---|---|---|
| A 三張照片局部疊合 | 拖動可即時控制透明度，保留原底圖；中間輪廓仍可能疊影 | 現有三張 WebP 約 1.14 MB，零新增資產與套件 |
| B 增加局部影格 | 對齊後可縮短疊影時間，仍能精確控制進度 | 需製作、審核並壓縮每張嘴部素材，前端可沿用圖層 |
| C 可拖動的局部影片或影格表 | 真正連續的素材可改善動作，但影片需驗證拖曳定位與解碼延遲 | 製作成本較高，影格表增加解碼記憶體，影片在各手機的行為需分別驗收 |

先採 A。保留閉嘴底圖與原遮罩，逐段疊合翻唇及露牙；放開時回落，計分立即停用。指標每幀更新 CSS 透明度與 SVG 位置，保留五階段規則與原結果格式。簡潔 SVG 刷頭可維持命中點精準，手指接觸以跟隨拖動的提示標記呈現。擬真透明手部會增加遮擋與不同裝置指尖對位成本，等瀏覽器確認標記是否足夠後再決定。

照護文案描述輕翻嘴唇、刷外側露出的牙齒，貓咪抗拒時放手休息。圖像為 AI 模擬，牙位熱區是遊戲目標。參考 [Cornell University College of Veterinary Medicine](https://www.vet.cornell.edu/about-us/news/20180221/veterinary-tips-pet-dental-care)。

## 若出現明顯疊影，先補兩張嘴部影格

圖像編輯指令：「使用 brush-closed.webp 當固定母圖，brush-lift.webp 與 brush-teeth.webp 僅作嘴部動作參照。輸出兩張同座標影格，分別是開始輕翻上唇，以及半露出外側牙面。只在影像右側嘴部區域編輯（參考 x=.50–.73、y=.50–.65），保持下顎自然閉合。不新增牙齒、手部或刷具。區域外的鼻頭、眼睛、鬍鬚根部、耳朵、毛色、背景、鏡頭、曝光全部與母圖像素對齊。每張 1086×1448，無文字、無重新取景。」

保留無損母檔，確認嘴部區域外差分、嘴角與牙面對位後，將局部區域以同尺寸透明 WebP 或附原點座標的裁切 WebP 匯出。先以逐格檢查 25%、50%、75% 進度，確認牙齒無雙邊緣，再在 375px 實際拖曳。

## 驗收

以 1280px 滑鼠加空白鍵完成一次 Lv.4，檢查停刷不計分及放開後閉嘴。以 375px 模擬兩指按下、刷牙與先放開翻唇指，檢查嘴部對位、圖層邊緣、版面與正確結果。實機另測 iPhone Safari 與 Android Chrome。自動測試涵蓋載入錯誤、滑鼠懸停、雙指狀態、鍵盤過渡和命中計分。

## 口腔特寫、五階段工具與情緒回饋

- 整體鏡頭放大會移動全臉與持續拖曳的嘴角。本次改用固定全臉上的獨立特寫，原翻唇指標仍由外層捕捉，另一指可在特寫內操作。
- 特寫以原圖正規化範圍 x=.375–.735、y=.483–.636 裁切，顯示寬度為全臉的 85%，等於同一畫面比例下約 2.36 倍。SVG viewBox 和指標逆轉換共用裁切範圍；SVG 工具接觸點與熱區使用原圖座標。
- Lv.0、Lv.1 使用手指，Lv.2 改為嘴唇旁的牙膏手指，Lv.3 與 Lv.4 在特寫中使用指套與軟毛牙刷。牙齒熱區沿合成影像的近似外側牙齦邊緣排列，不能用於解剖定位或測量實際刷毛角度。
- 保持輕翻唇、輕柔小幅刷動、刷毛朝牙齦與牙齒長軸約 45°，貓咪抗拒即停。參考 [Cornell 貓咪牙科照護](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/feline-dental-disease)、[VOHC 刷牙指引](https://vohc.org/brushing/) 與 [WSAVA 牙科指南](https://onlinelibrary.wiley.com/doi/full/10.1111/jsap.13132)。
- 耐心剩 30% 時提示放慢，既有掙扎時收唇並提示放手；咬人時立即閉嘴、移除刷具、停止互動；成功以薄荷色高亮和結果提示呈現。警訊和高亮提供減少動態設定。現有素材已能提供這些回饋，瀏覽器確認自然度之前不新增 GIF 或照片。

## 掙扎轉頭 POC（#356）

- 進入掙扎時收起刷具和特寫並釋放指標捕捉。原本持續按住的嘴角仍會累積咬人壓力。影片播放中停止計分，影片與掙扎區間結束後才能重新操作。
- 核准素材放在 public/play/brush/brush-turn-away.mp4，建置時設定 NEXT_PUBLIC_BRUSH_REACTION_MP4=/play/brush/brush-turn-away.mp4。未設定時只使用閉嘴 WebP，沒有影片請求。拒播、載入失敗、2.5 秒逾時、減少動態效果皆走靜態回退。
- 建議交付 540×720、24 fps、H.264/yuv420p、無聲、faststart MP4，以 250 KB 以下為目標。

### 圖生影片提示詞

以 brush-closed.webp 作為首影格及唯一身份參考。固定直式 3:4 鏡位、取景、光線及背景。保留同一隻虎斑貓的毛色、條紋、眼睛、鼻子、鬍鬚、臉型與比例。貓先自然正視，耳朵微微向後，接著平緩而清楚地把頭轉向一側避開接觸。全程自然閉嘴，頭、脖子與鬍鬚連貫移動；短暫穩住後自然回到接近首幀的閉嘴姿勢。不要張大嘴、齜牙、做攻擊表情、加入手、牙刷、背景物件、其他貓、字幕或浮水印。不要移動鏡頭、改變構圖或讓五官、鬍鬚與背景變形閃爍。全段 0.8～1.5 秒，無音軌。
