# 第 3 份：刷牙、摸貓（約 12.5 點）

**程式 ID**：小遊戲 `brush`、`pet`；道具 `brush_mouth`、`brush_toothbrush`；附帶畫面 `home`（`CareBar` 圖示列）、貓頭頂氣泡（ID 同小遊戲，加 `heart`、`hiss`）。完整對照見總表「程式 ID 對照表」。

刷牙是這份最重的部分。你從頭做到尾：**找貓嘴（2D 圖或 3D 模型）、牙刷，做出雙手操作的刷牙**；另外做 3D 摸貓。共通規格、結果格式、完成條件見 00-總表.md。

## 刷牙（約 7.5 點）

### 玩法（發起人構想）

- 畫面特寫貓的臉。
- **一隻手滑開貓的嘴角**：嘴巴打開一角，才看得到牙齒（放開就合起來）。
- **另一隻手拿牙刷滑過牙齒**：來回刷，刷到的牙齒變乾淨。
- 刷完規定的範圍算完成。

手機上用**兩根手指同時操作**；電腦用其他方式代替（例如按住一個鍵＝撐開嘴角），自己設計，寫在畫面提示裡。

### 難度（依信任）

- 拿得到貓目前的信任、壓力（`MiniCtx.cat.trust`、`cat.stress`）。
- **信任不足**：貓會**搖頭掙扎**（嘴巴合起來、要重新撐開），而且**能刷的時間短**（耐心值用完貓就跑掉 `ran`）；太勉強會咬（`bitten`）。
- 信任高：搖頭少、時間長。
- 遊戲裡已經有「刷牙練習階段」（`MiniCtx.brushLevel` 0～4，每練一次升一階），可以讓初期只要求碰嘴邊、後期才刷全口。
- 分數 `score` ≥ 60 才算做好。

### 2D 還是 3D

**可以做 2D 特寫**：貓臉的圖，嘴巴合起、打開一角兩種狀態，看得到牙齒與牙齦；牙刷是可拖曳的圖。3D 也可以，但要看得清楚牙齒。 貓臉的毛色要和這隻貓大致吻合（至少幾種常見毛色）。

| 項目 | 點數 |
|---|---|
| 貓臉／貓嘴圖或模型（合起、打開一角、牙齒乾淨／髒）＋牙刷 | 2 |
| 雙手操作（撐嘴角、刷牙） | 3 |
| 依信任的搖頭掙扎、時間限制、咬、跑掉 | 1.5 |
| 練習階段、計分、結果格式與測試 | 1 |

## 3D 摸貓（約 3 點）

- 手指在 3D 房間裡滑過貓身，用射線判斷摸到哪裡：頭、下巴、背有愛心；肚子、尾巴不能碰；耳朵往後壓要立刻放開。
- **最愛的地方**愛心最多：資料已讀進 `PlayCatSource.touchFav`（head／chin／back，來自中途填的摸摸地圖），還沒接進遊戲，這份接上；沒有資料（null）就隨機或用預設。
- 被摸的享受、舔毛、不爽的動作由第 4 份做，你負責「摸到哪裡叫貓播哪個動作」。
- 結果 `ran`、`fun`（沒跑掉且開心 ≥ 50 算做好）。
- 2D 版參考 `minis.ts` 的 `startPet`。

## 驗收

- 刷牙：雙手操作可行，信任低的貓明顯比較難；結果格式照總表（`bitten`、`ran`、`score`）；入口是在家的時光 🦷 與劇情第 30 天。
- 摸貓：在 3D 房間內操作，最愛的部位愛心最多；結果格式照總表。
- 圖示列與氣泡是同一套圖示。

## #356 自由視角與身體語言

開發模式可開啟 `/dev/pet-orbit`，使用正式摸貓彈窗。背景拖曳旋轉、滾輪縮放、按鈕回正；頭、下巴或背部可輕柔試摸。觸碰部位由同一條射線判斷並顯示名稱。

成貓 GLB 有 39 個關節，包含 `neck0/1`、`head0`、左右耳、`jaw`、脊椎與 `tail0–6`。眼睛是獨立網格；`cat_base` 有 `blink_L/R` Morph Targets。`idle`、`cuddle` 各 4 秒，`walk` 1 秒，沿用現有混合。早期抗拒使用 `head0` 的小幅加成轉頭，放手後隨煩躁下降淡回。減少動態時以相同狀態文字提示。耳朵、尾巴和眨眼目前維持原動畫。

玩家看到轉頭或離開時先停手，觀察牠是否想繼續。偏好因個體及情境而異。
