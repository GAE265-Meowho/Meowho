# 第 4 份：貓咪動作與老化（約 11 點）

**程式 ID**：貓的姿勢 `CatPose`（`sit` `hide` `sofa` `zoom` `frail` `bed` `table` `carrier` `none`）；新動作 ID 由你訂好公布在 Issue；年紀對應節點 `day1`～`farewell`。完整對照見總表「程式 ID 對照表」。

你負責「貓本身」：**貓全身的動作、熟齡與老貓的樣子、真實貓的花色貼圖**。做成貓模型（母體 glb）裡的動作片段，給第 1、2、3 份叫用。共通規格見 00-總表.md。 「什麼時候叫貓播哪個動作」由第 1～3 份寫；讓模型隨年紀換的**程式**由第 5 份寫。

## 現在貓會隨年紀換模型嗎？

**3D 掃描房間（真正的遊戲畫面）不會。** 永遠是全站預設的成貓母體（`/hq-cat-models/base/base_clips.glb`），花色也不是這隻貓的。只有「示範娃娃屋」會以 12 個月為界換幼貓／成貓。沒有熟齡、老貓模型。（讀程式得出的結論，沒有用真實中途貓實測；修程式是第 5 份。）

## 已有的動作（待確認，認領前請核對母體實際內容）

idle、walk、sleep、sit、jump A／B／C、從櫃子往下跳。**現有動作名稱不能改**（`src/lib/play/cats.ts` 檔頭說明）；新動作的名稱先在 Issue 公布，讓第 1～3 份照著叫。

## 驗收

- 每個劇情姿勢（`CatPose`：sit、hide、sofa、zoom、frail、bed、table、carrier、none）都有對應動作。
- 3 個月、2 歲、10 歲、15 歲的貓看起來明顯不同；花色是真實貓的（搭配第 5 份的程式驗收）。
- 新動作名稱公布在 Issue，第 1～3 份能叫得到。
