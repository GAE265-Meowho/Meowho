# 第 1 份：鏟屎、餵貓、換水（約 12.5 點）

**程式 ID**：小遊戲 `scoop`、`feed`、`water`（`play` 只做玩具確認）；物件 `litter_box_open`／`litter_box_covered`／`litter_box_large`／`litter_box_kitten`、`toy`；道具 `scoop_poop`、`scoop_clump`、`scoop_shovel`、`scoop_bag`、`feed_bag`、`feed_can`、`water_jug`；附帶畫面 `StatusMeters`。完整對照見總表「程式 ID 對照表」。

每天最常做的三件日常，你從頭做到尾：**3D 小遊戲、需要的 3D 模型都自己找或做，並設定貓跟這些物件怎麼互動**。共通規格、結果格式、完成條件見 00-總表.md。

## 目標

玩家在自己的 3D 房間裡親手鏟貓砂、倒飼料、換水；貓砂盆裡看得到 3D 大便與結塊。

## 現況

- 2D 版在 `src/components/play/catgame/minis.ts`（`startScoop`、`startFeed`、`startWater`），可當玩法參考。
- 房間裡已有 3D 用品（`src/lib/play/items.ts`）：外出籠、餐碗組（飯碗水碗同一個模型，不拆）、貓砂盆（只有一款）。
- 入口：在家的時光（🍚💧💩 圖示）；劇情第 3 天（餵第一餐、鏟屎）。

## 要做的事

| 項目 | 點數 | 說明 |
|---|---|---|
| 鏟屎模型 | 1.5 | **3D 大便**、**3D 貓砂結塊**（大小數個）、**貓砂鏟**、垃圾袋；大便與結塊要**放在貓砂盆的砂裡**（半埋） |
| 貓砂盆四款 | 2 | 開放式、有蓋、大尺寸、幼貓小尺寸（採買的四個選項），外觀與尺寸不同；採買選哪款就用哪款 |
| 3D 鏟屎 | 3 | 鏡頭靠近貓砂盆，拖鏟子把大便、結塊鏟起放進垃圾袋；動作太大會掉回去 |
| 餵貓、換水模型 | 1 | 乾飼料袋、主食罐、湯罐（有拉環）、飼料顆粒；水壺（倒出的水可用粒子或半透明） |
| 3D 餵貓 | 2 | 拖飼料袋／罐頭到餐碗上方倒出，份量到建議值；倒完叫貓走到碗邊吃 |
| 3D 換水 | 1 | 拖水壺到餐碗的水碗側倒水到 70% 以上；之後叫貓去喝 |
| 貓與物件互動設定 | 0.5 | 餵完貓走去吃、換完水去喝、貓去上廁所後砂盆出現新的大便（動作由第 4 份做，你負責「什麼時候叫貓去」） |
| 附帶：逗貓玩具確認 | 0.5 | 3D 逗貓已經做好；後台的老鼠玩具模型確認外觀、大小合理，需要就換一個 |
| 附帶：上方狀態列 | 1 | `StatusMeters.tsx`：信任五顆愛心、壓力五顆火焰，做正式圖樣與數值變動時的小動畫 |

道具可以先用方塊代替，把互動做出來再換模型。

## 驗收

- 三個小遊戲在 3D 房間內操作，結果格式照總表（鏟屎任何、餵貓 `over`／`added`／`spill`、換水 `fill`）。
- 第 3 天劇情與在家的時光都能開；做好圖示變半透明，取消不變。
- 貓砂盆四款都能放進房間，不穿牆、不穿家具；砂盆裡看得到大便與結塊，鏟掉就消失。

## 相依與提醒

- 吃東西、喝水、上廁所的動作由第 4 份做；做好之前貓先 idle。
- 音效（倒飼料、開罐頭、倒水、鏟砂）由第 6 份做，你在程式留好「什麼時候播」的位置。
- 拖曳道具時要停用「拖曳轉視角」（逗貓已經這樣做），不然手指會轉到鏡頭。
- 新功能寫在自己的檔案（例如 `src/components/play/mini3d/`）。
