# 第 2 份：剪指甲、外出籠、貓抓板（約 12.5 點）

**程式 ID**：小遊戲 `nail`、`carrier`；物件 `carrier`、`scratcher`；道具 `nail_paw`、`nail_clipper`。完整對照見總表「程式 ID 對照表」。

剪指甲是這份最重的部分。你從頭做到尾：**找貓的手掌（2D 圖或 3D 模型）、指甲刀，做出雙手操作的剪指甲**；另外做外出籠小遊戲與貓抓板。共通規格、結果格式、完成條件見 00-總表.md。

## 剪指甲（約 7.5 點）

### 玩法（發起人構想）

- 畫面特寫**一隻貓的手掌**。
- **一隻手（一根手指）按住貓的腳趾**：按下去指甲才會伸出來（放開就縮回）。
- **另一隻手拿指甲刀**：拖到指甲上，對齊要剪的位置。
- **放開＝剪下去**。剪在指甲前端白色的尖端＝成功。
- **剪太裡面（剪到粉紅色的血線）**：指甲**流血**（畫面上看得到血），貓**尖叫＋哈氣**，結果 `bleed: true`，這次算沒做好；貓的壓力上升、信任下降由遊戲公式處理。尖叫、哈氣的聲音由第 6 份做，哈氣的樣子在特寫裡由你畫（2D 表情或 3D 動作）。
- 一隻腳有幾根指甲，全部剪完算完成。

手機上要用**兩根手指同時操作**（多點觸控）；電腦可以用「按住空白鍵＝按腳趾」或滑鼠先按一下固定腳趾代替，請自己設計，寫在畫面提示裡。

### 2D 還是 3D

**可以做 2D 特寫**（發起人同意）：一張貓掌的圖，指甲伸出／縮回兩種狀態，血線清楚。2D 比較容易看清楚、也比較好做；3D 也可以，但要能放大到看得到血線。 貓掌的毛色要和這隻貓大致吻合（至少有幾種常見毛色：橘、黑、白、虎斑、三花）。

### 難度

- 拿得到貓目前的信任、壓力（`MiniCtx.cat.trust`、`cat.stress`）。信任低或壓力高：貓會抽腳（指甲縮回、要重按）、超過幾次會咬（`bitten`）或跑掉（`ran`）。
- 剪越準分數越高（`score`，≥ 60 才算做好）。

| 項目 | 點數 |
|---|---|
| 貓掌圖或模型（伸出／縮回、血線、幾種毛色）＋指甲刀 | 2 |
| 雙手操作（按腳趾、拖指甲刀、放開剪） | 3 |
| 依信任、壓力的難度（抽腳、咬、跑掉）與計分 | 1.5 |
| 剪太深：流血畫面、貓尖叫哈氣的反應 | 0.5 |
| 結果格式與測試 | 0.5 |

## 貓抓板（約 1 點）

找或做貓抓板 3D 模型、登錄尺寸、放進房間（採買預設有買）；設定貓偶爾走去磨爪（磨爪動作由第 4 份做）。

## 附帶：穿模修正（約 1.5 點）

擺好用品後，貓有沒有穿過家具或 3D 用品？程式已擋用品、貼家具的箱子（`src/lib/play/scene-items.ts`），但沒有人在畫面上確認過貓走動。請實際玩幾種房間，發現穿模就修。第 1 天貓躲進外出籠是例外（要能進去）。

## 驗收

- 剪指甲：雙手操作可行，結果格式照總表（`bleed`、`bitten`、`ran`、`score`）；入口是在家的時光 ✂️ 與劇情半年後。
- 外出籠：第 10 年劇情能玩，成功回 `{ ok: true }`。
- 貓抓板在擺用品、劇情裡都能放進房間，貓繞開或去磨爪。
- 穿模：記錄測了哪些房間、修了什麼。
