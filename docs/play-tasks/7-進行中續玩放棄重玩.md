## 一、`/run` 現在的流程（可以沿用的部分）

頁面在 `src/app/cats/[id]/run/page.tsx`，規則在 `src/lib/task-run.ts`，資料庫在 `0017_meow_adoption_tasks.sql` 第 8 節。

### 資料表 `meow_task_runs`

| 欄位 | 用途 |
|---|---|
| `member_id`、`cat_id` | 誰在做哪隻貓 |
| `version_id` | 任務版本（`meow_cat_task_versions`） |
| `room_model_id` | 開始時用的是哪一間 3D 房間 |
| `status` | `in_progress`／`completed`／`abandoned`（這次要加 `closed`） |
| `progress` | 進度 JSON，上限約 50 KB。**本人可以直接 update**（只限進行中那筆） |
| `game_report` | `/play` 的試養報告（0033 加的），上限約 30 KB |
| `proof_shared_at` | 有沒有附給中途 |
| `started_at`、`finished_at` | 開始、結束時間 |

- 唯一索引 `meow_task_runs_one_active`：**一個人同時只能有一筆 `in_progress`**。
- trigger `meow_task_run_guard`：本人只能改進行中那筆的 `progress`，改不了狀態、貓、時間。
- `meow_task_abandons`：放棄標籤。**本人讀不到，只有那隻貓的中途讀得到**。

### 函式

| 函式 | 做什麼 | 會擋的情況（錯誤代碼） |
|---|---|---|
| `meow_start_task_run(貓, 房間)` | 建一筆進行中；已經在做同一隻就回傳原本那筆 | 沒有喵戶 `household_required`、貓不是待領養或是自己的貓 `run_cat_not_ready`、房間不是自己的或沒建好 `run_room_not_ready`、正在做別隻 `run_in_progress` |
| `meow_abandon_task_run(紀錄, 原因[], 說明)` | 改成 `abandoned`，寫一筆放棄標籤 | 沒選原因、選「其他」沒寫說明 |
| `meow_complete_task_run(紀錄)` | 改成 `completed` | 還有任務沒做完 `run_not_complete` |
| `meow_share_task_proof(紀錄)` | 開對話串，留「附上了領養任務證明」 | 不是完成的紀錄 |
| `meow_thread_task_status(對話串)` | 對話串顯示用：是否完成、試養報告、放棄標籤（只給中途） | — |

### 畫面的判斷順序（`RunPage`）

1. 沒登入或沒有喵戶 → `useHouseholdGate().pass(here)` 帶去登入或建喵戶，回來接著做。
2. 貓不是待領養 → 「目前不能進行領養任務」。
3. 這隻貓做完過、而且現在沒有進行中 → 完成畫面，可以「帶著試養報告聯絡中途」。
4. 正在做**別隻貓** → 「你正在進行〈貓名〉的領養任務」，兩顆按鈕：回去完成／放棄那隻的任務。
5. 沒有建好的 3D 房間 → 引導去建。
6. 都通過 → 選房間、按「開始任務」→ 先 `POST /api/cats/[id]/tasks/prepare`，再 `meow_start_task_run`。
7. 進行中：每選一個選項就 `update progress`；全部做完呼叫 `meow_complete_task_run`。
8. 任何時候可以按「放棄任務」→ `AbandonPanel`：原因必選（可複選：時間不夠、覺得自己還沒準備好、覺得不適合這隻貓、想先試別隻貓、任務太難、其他），「其他」要寫說明。

### `/play` 目前跟它差在哪

- `PlayGame.tsx` 的遊戲狀態只在前端，重新整理從頭開始。
- 玩完才呼叫 `meow_save_play_report`，直接插入一筆 `completed`，從來沒有 `in_progress`，所以「一人一隻」的限制對 `/play` 沒有作用。
- 沒有 3D 房間時會用公開示範房間、沒有報告時用規則算危險，照樣能玩。

## 二、定案的新流程

### 1. 貓咪頁的按鈕

| 這個人的狀態 | 按鈕文字 | 按下去 |
|---|---|---|
| 沒有進行中，這隻貓也沒做完過 | 進行領養任務 | 走「開新一輪」的檢查（第 2 點） |
| 正在做**這隻貓** | 繼續領養任務 | 彈窗：**繼續任務**／**殘忍放棄** |
| 正在做**別隻貓** | 進行領養任務 | 彈窗寫出貓名：「你正在進行 cookie 的領養任務」→ **繼續 cookie 的任務**／**放棄，改做妹妹的** |
| 這隻貓做完過（沒有進行中） | 再做一次領養任務 | 確認彈窗（第 6 點） |

- 喵戶長看自己的貓不顯示這顆按鈕，維持現狀。
- 完成時間**不放在按鈕旁邊**（前台不放小字備註），放進「再做一次」的確認彈窗。

### 2. 開新一輪前的檢查（缺什麼就擋下來，說明下一步）

| 檢查 | 沒過的時候 |
|---|---|
| 有登入 | 先登入，回來接著做（`useHouseholdGate`） |
| 有**個人喵戶**（`cat_owner`）；只有中途喵戶不算 | 導去建喵戶，回來接著做 |
| 有建好的 3D 房間，而且有這間房間的居家安全報告 | 還沒上傳：擋住，導去 `/homes/[id]/scene` 上傳 |
| 房間或報告**還在處理中** | 擋住，告訴他模型正在做、請稍等（好了會通知），給一顆按鈕去看其他貓 |
| 貓有確認過的 3D 模型 | 不用檢查。中途讓貓出發前就一定確認過 |

**不再用示範房間和規則危險當備案**。「五年後的意外來自你家的安全報告」是主線，沒有自己的房間和報告就不開始。（示範模式、沒連資料庫的情況照舊。）

### 3. 開始時把資料定格

開始的那一刻記下：用的是哪個喵戶、哪一間房間、哪一份安全報告。**這一輪從頭到尾都用這一份**，玩到一半重新上傳影片也不換；新上傳的資料下一輪才用。

- 房間已經有 `room_model_id`。
- 安全報告要加一個欄位記報告 id（建議 `env_report_id`）。
- 喵戶背景、預算、貓的資料：建議開始時一起存進進度 JSON，續玩時讀存的那份。

### 4. 存進度（連進度一起存，可以換裝置）

- **每過一個節點存一次**，不要每個動作都存。
- `PlayState`（`src/lib/play/flow.ts`）不能整包存：`queue` 和 `cur` 裡有函式。要存的是「節點開始時的快照」，續玩時**從那個節點的開頭**重新開始，節點裡玩到一半的部分會重來。
- 快照至少要有：`step`、`nodeIndex`、`life`（信任、壓力、選過的選項、花費、照顧紀錄）、`hazards`、`handled`、`monthly`、`startMonths`，加上採買的選擇（`pick`）和擺放的位置（`placed`、`scanSpots`）。
- 存在 `meow_task_runs.progress`（本人可以直接 update）。注意上限約 50 KB，`life.picks`、`notes`、`events` 會一直長，要確認玩到最後不會超過。
- 存在資料庫，所以手機玩到一半，電腦可以接著玩。

### 5. 放棄

| 情況 | 要不要選原因 | 中途看不看得到 |
|---|---|---|
| 在**這隻貓**的任務裡按「殘忍放棄」 | 要（沿用 `ABANDON_REASONS`） | **看得到**：這隻貓的中途在對話串會看到「放棄過領養任務」和原因 |
| 為了**換貓**而放棄另一隻 | 不用 | **看不到**：不寫放棄標籤 |

- 「殘忍放棄」按下去先說明後果：這隻貓的中途會看到你放棄過，以及你選的原因。確認後才放棄。
- 換貓那種要另外處理：現在的 `meow_abandon_task_run` 一定會寫標籤，需要一個「不寫標籤」的做法（新函式或多一個參數）。
- 放棄後就可以開始別隻貓。

### 6. 完成與重玩

- 完成時把進行中那筆改成 `completed` 並寫入 `game_report`。**不能再用 `meow_save_play_report` 另外插一筆**，不然進行中那筆會一直留著。
- **重玩不覆蓋，每次都留一筆**。中途看到「最新一次」的報告，加上「共完成幾次」。
- 「再做一次」的確認彈窗寫：上次完成的時間；再做一次會多一筆紀錄，中途看得到你做過幾次。
- `meow_thread_task_status` 要多回「完成幾次」。

### 7. 回任務的入口

- **全站右下角固定一顆按鈕**：有進行中的任務時才出現，顯示貓名和進度（例如「妹妹的任務 2／3」），按了回 `/cats/[id]/play`。
- 任務頁本身不顯示。位置先做出來，之後再調；手機要避開底部導覽。
- 另外兩個入口：「我的喵戶」頁、貓咪頁的按鈕（第 1 點）。
- 重點是**一定要有一個入口提醒使用者還有任務沒做完**。

### 8. 貓不再待領養

任務做到一半，貓被領養或下架了：**進行中的那筆自動改成 `closed`（已結束）並通知領養人，不算放棄**（不寫放棄標籤）。
放太久沒動的過期規則先不做。
