# 第 6 份：音效與配樂（約 7 點）

**程式 ID**：背景音樂 `bgm_*`、音效 `sfx_*`（全部新定，清單見總表「程式 ID 對照表」→ 聲音）。檔名照 ID，例如 `bgm_daily.mp3`。

遊戲目前**沒有任何聲音**。你負責所有聲音：**背景音樂、音效，以及播放聲音的程式**。**不做人聲配音**，台詞維持文字呈現。這份只做音樂與音效。共通規格見 00-總表.md。

## 一、背景音樂（5 首，約 2.5 點）

| 曲名 | 什麼時候播 | 感覺 |
|---|---|---|
| 剛到家 | 第 1 天（貓躲在外出籠、等牠出來） | 安靜、小心翼翼、有一點期待 |
| 日常 | 第 3 天、在家的時光、平凡的一天、五年後與十年後在家的段落、開場（你的家、採買、擺用品）、試養報告 | 溫暖、輕快，可以長時間循環不煩 |
| 半夜 | 第 30 天半夜跑酷、半年後半夜噴尿／發情大叫、第 1 天硬拉那晚 | 夜晚、輕微調皮或不安 |
| 醫院 | 看獸醫（半年後、五年後、十年後） | 乾淨、略緊張但不嚇人 |
| 升天 | 結尾 15 歲 | 溫柔、感傷、有陪伴感 |

- 要能無縫循環（升天除外）。
- 選做：五年後「居家意外」發生的瞬間一個短的緊張音效（不是整首）。

## 二、音效（約 2.5 點）

| 類別 | 音效 | 用在 |
|---|---|---|
| 貓的聲音 | 一般喵、撒嬌喵、呼嚕、哈氣（嘶聲）、**尖叫**（剪指甲剪太深）、**半夜發情大叫**（又大又長，母貓） | 摸貓、刷牙、剪指甲、第 1 天硬拉、半年後 |
| 貓的動作 | 腳步聲（木地板）、跑酷衝刺、跳上家具落地、吃飯（咀嚼）、喝水（舔水）、撥貓砂、磨爪、噴尿 | 房間裡貓走動、吃喝、上廁所、貓抓板、半年後 |
| 照顧動作 | 倒飼料、開罐頭拉環、倒水、鏟貓砂、垃圾袋、剪指甲「喀」、刷牙「刷刷」、外出籠門開關 | 第 1～3 份的小遊戲 |
| 逗貓 | 玩具在地板上跑、貓撲上去 | 3D 逗貓 |
| 介面 | 按鈕、信任上升（愛心）、壓力上升、完成、失敗 | 全部畫面 |

貓的叫聲可以錄真貓（組員家的貓）或找可商用素材；要附授權（自己錄的寫「自錄」）。

## 三、播放程式（約 2 點）

- 新增 `src/lib/play/audio.ts`（或類似）：依場景（`scene.bg`、`scene.time`、節點、在家的時光）切換背景音樂，淡入淡出。
- 音效 API：第 1～5 份在對的時機呼叫（例如 `playSfx("pour")`），你先定好音效名稱清單公布在 Issue。
- **手機瀏覽器規定使用者點過畫面才能播聲音**：第一次播放要掛在使用者的點擊（例如「下一步」按鈕）。
- 畫面上方加一個「音量／靜音」按鈕（記住玩家的選擇）。
- 音檔用 mp3 或 ogg，壓小檔案（手機流量）。放 Supabase Storage `meow-play-audio`（2026-11-13 定案，見下方「音檔在哪裡、怎麼用」）。

## 音檔在哪裡、怎麼用（2026-11-13，#393）

**音檔放在 Supabase Storage** 的公開 bucket `meow-play-audio`（0035）：

- 背景音樂：`bgm/<ID>.mp3`，例如 `bgm/bgm_daily.mp3`
- 音效：`sfx/<ID>.mp3`，例如 `sfx/sfx_yowl.mp3`
- 每個音檔旁邊有同名的 `<ID>.license.txt`；repo 裡的副本在 `docs/play-tasks/音檔授權/`

**對照表在程式裡**：`src/lib/play/audio.ts` 的 `SOUNDS`，每個 ID 寫了名稱、用在哪個事件、第幾份要呼叫、有沒有音檔。不用自己組網址：

```ts
import { playSfx } from "@/lib/play/audio-player";
import { SOUNDS, soundsFor, audioSrc } from "@/lib/play/audio";

playSfx("sfx_yowl");      // 在對的時機呼叫；還沒有音檔就不出聲、不報錯
soundsFor(5);             // 第 5 份（渝茜）要接的音效 ID
SOUNDS.sfx_yowl.usedIn;   // 「半年後，母貓未結紮半夜發情」
audioSrc("sfx_yowl");     // 完整的 Supabase 公開網址（要自己用 <audio> 播時才需要）
```

背景音樂**不用呼叫**，會依步驟、節點、`scene.bg`、`scene.time` 自動切換（`bgmFor()`）。

### 補音檔（子哲）

1. 檔名改成 ID（`sfx_meow.mp3`），旁邊放 `sfx_meow.license.txt`（格式照 `docs/play-tasks/音檔授權/`）。
2. `npm run audio:upload -- <資料夾>` 先預覽，確認後加 `--apply` 上傳。不認得的檔名、缺授權檔的會略過。
3. 把 `audio.ts` 裡那個 ID 的 `ready` 改成 `true`，授權檔副本放進 `docs/play-tasks/音檔授權/`，開 PR。

## 驗收

- 五首背景音樂在對的段落播放、切換時淡入淡出；靜音按鈕有效。
- 音效名稱清單公布；日常三件（餵、喝、鏟）、剪指甲剪太深的尖叫與哈氣、半夜發情大叫已接上。
- 所有音檔附授權。

## 相依與提醒

- 場景切換的時機由第 5 份提供；小遊戲音效的時機由第 1～3 份在程式留位置。
- 噴尿、發情大叫的貓動作由第 4 份做；尿漬由第 5 份做。聲音要和動作、尿漬同時出現。
