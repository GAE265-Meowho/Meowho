# 虛擬飼養劇情審稿（J 劇情審稿，附帶 1 點）

- 發起人：渝茜（#354）　審稿基準：`main` 的 `12c1175`　審稿者：Claude Code（claude-sonnet-5-5）
- 範圍：`src/lib/play/story.ts`、`care.ts`、`lines.ts`、`needs.ts`、`report.ts`，以及 `src/components/play/catgame/minis.ts` 玩家看得到的文字。
- 任務表提到的 `故事文字總整理.md` 不在 repo 裡，所以這份是直接對照程式裡的劇情審的；原稿若找到，需再對一次。
- 本文件只列問題與建議改法，沒有改任何程式或劇情檔。「建議改法」是候選句，採不採用由組員決定。
- 時間軸背景：`timeline.ts` 會把劇本時間換成這隻貓的真實月齡。前半年照劇本，之後的「五年後／十年後／結尾」會依剩餘年數壓縮（結尾最多 20 歲，老貓的「五年後」可能只過 1～2 年）。下面很多「年齡或時間對不上」都來自這點。
- 讀法：位置寫成「檔名／節點 ID／原句開頭」。嚴重度：高＝會讓玩家覺得錯或有醫療疑慮、中＝明顯不順或矛盾、低＝措辭。
