# 007 居家環境影像的保存與分享規則
- 日期：2026-10-31
- 發起人 × 工具：子哲 × Claude Code (claude-opus-5-5)
- 背景：領養人要拍家裡的影片或照片來建 3D 場景和環境報告。這些影像等於把家完整掃描出來，是全站最敏感的資料；原規則「居家環境影片在貓咪移轉完成時刪除原檔」保存太久。喵戶長又需要看到證據，才能在 AI 意見之外給建議。
- 決定：
  - **3D 場景和環境報告都產出後，立即刪除居家環境的原始影片和照片**，只保留：3D 場景、環境報告（文字與風險項目）、**發現風險的裁切照**（從影片或照片截出，裁到只剩風險物品）。
  - **3D 場景只有領養人自己看得到**。
  - **環境報告預設只有領養人看得到**；領養人在私訊中按「分享環境報告」後，該位喵戶長才能看到報告、文字和風險裁切照。
  - 喵戶長可以針對每個風險項目寫建議，領養人看得到（本週只留資料欄位，畫面下週做）。
  - 貓的影片不受此規則限制：每隻貓最多 3 支、每支 60 秒內，喵戶長刪除這隻貓時一起刪除。
- 影響：
  - `AGENTS.md` §6 業務規則改寫。
  - 環境建模（#60 世安、#61 珮瑜、渝茜）的管線要在產出後呼叫刪除；風險裁切照要在刪除前產生。
  - 私訊（#70）要提供「分享環境報告」的動作。
- 替代方案（未採用的原因）：
  - 移轉完成時才刪（未採用：可能保存數週，外洩風險高）
  - 全部原始影像都刪、喵戶長只看文字（未採用：喵戶長需要看到證據才能給建議）
  - 3D 場景也給喵戶長看（未採用：等於公開整個家，超出給建議的需要）

## 補充：平面圖轉換的原圖保留（2026-11-02，Tina × Claude Code，#138）
- MeowHQ「平面圖轉換」上傳的房間平面圖**保留，管理員可預覽原圖**（規格 `docs/hq/05` Q12），是本決策「產出後刪除原始影像」的例外。
- 理由：平面圖是格局圖，不是居家實景照片；AI 讀錯時要把線框疊在原圖上修正，刪了就無法修正。第一版只有後台管理員上傳示範用平面圖。
- 仍依本決策**不公開**：原圖放私有 Azure Blob（`floorplans/<戶>/<房間>`），預覽用 10 分鐘有效的 SAS 網址；刪房間或刪戶時一併刪原圖。
- 之後開放前台貓戶上傳自家平面圖時，要重新檢討是否保留。

## 補充：平面圖轉換接受室內實景照片並保留原圖（2026-11-03，Tina × Claude Code，#144）
- MeowHQ「平面圖轉換」也接受同一間房 1～4 張**室內實景照片**，由 AI 推估格局。Tina 決定這些照片**保留原圖**（可預覽、可重新讀圖），是本決策「產出後刪除原始影像」的第二個例外。
- 範圍限制不變：只有 MeowHQ 管理員上傳（示範用空間），原圖放私有 Azure Blob（`floorplans/<戶>/<房間>_<6 碼>`），預覽用 10 分鐘 SAS；刪照片、刪房間、刪戶時一併刪除。
- 前台領養人的居家影片與照片仍照本決策產出後刪除；之後若開放前台貓戶用實景照片做室內空間，要重新決定是否保留。


## 補充：居家健檢的完整 PDF 與失敗影片保留期限（2026-11-06，子哲 × Claude Code，#240、#242）
- **完整 Before／After PDF**（#240，世安提案、子哲 2026-11-06 採用 v0.4）：每次居家安全檢測產生 **1 份完整 PDF**（真實居家視角 Before、AI 模擬 After、局部特寫、照護建議）＋1 份結構化 JSON。這是本決策「只保留裁切照」的第三個例外。
  - 理由：全景對照是讓飼主看懂改善措施放進自己家會是什麼樣子的核心功能；競賽 Demo 不做雙 PDF 與額外同意流程。
  - 限制：**PDF 只有本人看得到**；在私訊分享報告給喵戶長時，只分享網站上的摘要、風險項目與裁切照，不授權 PDF；MeowHQ 後台也不提供下載。每張 After 圖與封面標明「AI 模擬示意，不代表已實際改善」。
  - 保存：放私有 Azure Blob，主站驗權後簽短效讀取連結；刪除報告或喵戶時一併刪除。
  - 原始影片照舊在產出後刪除，**不因為有 PDF 而延長保存**。
- **失敗影片最多留 7 天**（#242）：影片由獨立清理程式刪除，3D 與健檢工作都結束才刪；有工作失敗、等重試或等管理員重新排的影片，上傳超過 7 天一律刪除；上傳 24 小時沒被任何房間或報告使用的影片也刪除。
- 介面與欄位見 `docs/spec/10_居家環境健檢Worker契約.md`。
