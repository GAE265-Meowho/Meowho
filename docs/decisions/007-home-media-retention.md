# 007 居家環境影像的保存與分享規則
- 日期：2026-10-31
- 發起人 × 工具：子哲 × Claude Code (claude-opus-5-5)
- 背景：領養人要拍家裡的影片或照片來建 3D 場景和環境報告。這些影像等於把家完整掃描出來，是全站最敏感的資料；原規則「居家環境影片在貓咪移轉完成時刪除原檔」保存太久。喵戶長又需要看到證據，才能在 AI 意見之外給建議。
- 決定：
  - **3D 場景和環境報告都產出後，立即刪除居家環境的原始影片和照片**，只保留：3D 場景、環境報告（文字與風險項目）、**發現風險的裁切照**（從影片或照片截出，裁到只剩風險物品）。
  - **3D 場景只有領養人自己看得到**。
  - **環境報告預設只有領養人看得到**；領養人在私訊中按「分享環境報告」後，該位喵戶長才能看到報告、文字和風險裁切照。
  - 喵戶長可以針對每個風險項目寫建議，領養人看得到（本週只留資料欄位，畫面下週做）。
  - 貓的影片不受此規則限制：每隻貓最多 3 支、每支 60 秒內，喵戶長刪除這隻貓時一起刪除。
- 影響：
  - `AGENTS.md` §6 業務規則改寫。
  - 環境建模（#60 世安、#61 珮瑜、渝茜）的管線要在產出後呼叫刪除；風險裁切照要在刪除前產生。
  - 私訊（#70）要提供「分享環境報告」的動作。
- 替代方案（未採用的原因）：
  - 移轉完成時才刪（未採用：可能保存數週，外洩風險高）
  - 全部原始影像都刪、喵戶長只看文字（未採用：喵戶長需要看到證據才能給建議）
  - 3D 場景也給喵戶長看（未採用：等於公開整個家，超出給建議的需要）

## 補充：平面圖轉換的原圖保留（2026-11-02，Tina × Claude Code，#138）
- MeowHQ「平面圖轉換」上傳的房間平面圖**保留，管理員可預覽原圖**（規格 `docs/hq/05` Q12），是本決策「產出後刪除原始影像」的例外。
- 理由：平面圖是格局圖，不是居家實景照片；AI 讀錯時要把線框疊在原圖上修正，刪了就無法修正。第一版只有後台管理員上傳示範用平面圖。
- 仍依本決策**不公開**：原圖放私有 Azure Blob（`floorplans/<戶>/<房間>`），預覽用 10 分鐘有效的 SAS 網址；刪房間或刪戶時一併刪原圖。
- 之後開放前台貓戶上傳自家平面圖時，要重新檢討是否保留。
