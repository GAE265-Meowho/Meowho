# 開工引導詞（貼給你的 AI agent）

組員把下面整段複製，把 `NN` 換成自己認領的鏡號、`<工具>` 換成自己要用的影片生成工具，貼給自己的 AI agent（Claude Code、Cursor、Codex、Antigravity 都可以）。

```text
請幫我做前導影片第三段的「鏡 NN」片段（GitHub Issue #547）。影片生成工具我用 <工具>，用我自己的帳號／額度。

一、先準備（不花錢）
1. git switch main && git pull，開分支 docs/547-shotNN-<我的英文名>。
2. 依序讀完再動手：
   - docs/video/前導影片第三段_片段製作SOP.md（照這份做，規則在 §0）
   - docs/video/第三段素材包/讀我.md
   - docs/video/第三段素材包/鏡NN/素材清單.md（這一鏡的秒數、旁白、每格的首幀、參考圖、系統錄影）
   - docs/video/第三段素材包/鏡NN/分鏡計畫圖.jpg 和 格說明/*.txt
3. 在 docs/agents/PLAN.md 的「前導影片第三段片段」表，把鏡 NN 填上我的名字、狀態改「進行中」。
4. 確認你拿得到這些檔案並列給我看：分鏡計畫圖、每格的綠幕底圖、要掛的人物／場景參考圖、要用的系統錄影。少任何一樣先停下來告訴我。
5. 檢查 <工具> 符合 SOP §4.1（能指定首幀的圖生影片、4–5 秒、720p 以上、能關運鏡）。不符合就先告訴我。

二、給我確認（不花錢）
依 SOP §2、§3 列出：要做幾格、每格幾秒、對到哪句旁白、用哪張綠幕底圖、螢幕放哪支錄影的哪幾秒、每支 prompt，以及總共要花多少。錄影對不上畫面（手機／筆電、缺動作）就寫出補錄計畫。等我說可以再開始花錢。

三、製作
1. 照 SOP §4 生成，每支送出前跑 §4.4 的核對清單。一次做完整鏡，不要一格一格問我。
2. 照 SOP §5 驗收、§6 合成（scripts/trailer-board/ 的 green-corners.mjs、green-composite.sh）、§7 接成整鏡（join-shot.sh）。
3. 綠幕不穩、人物跑掉要重生時，先告訴我原因和要再花多少。

四、交付
1. 整鏡要剛好等於素材清單的秒數，規格 1280x720、SAR 1:1、30fps、無聲。抽一格放大給我看螢幕 UI 有沒有被壓扁。
2. 我確認後：上傳到 MeowHQ「前導影片：影片」鏡 NN 的片段卡；AI 原始片段、各格合成檔、整鏡放 docs/video/第三段素材包/鏡NN/成品/，並寫 成品/紀錄.md（SOP §10）。
3. 寫每日紀錄（npm run log），PLAN.md 改「審查中」，commit 帶 Initiated-by／Agent trailer，開 PR，最後給我合併指令：
   gh pr merge <PR 編號> --repo GAE265-Meowho/Meowho --merge --admin --delete-branch
```

## 組員自己要做的事

- 準備自己的影片生成工具帳號或額度。
- 用網頁工具的話，把這一鏡的綠幕底圖和參考圖拖進工具一次（瀏覽器 agent 通常不能幫你選檔案）。
- 確認 agent 列的格數、秒數、花費，再讓它開始花錢。
- 看成品，確認後讓 agent 上傳、開 PR。
