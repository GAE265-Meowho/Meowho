# 前導影片第三段（鏡 15–24）片段製作 SOP

> 2026-11-20 子哲與 Claude Code 依鏡 15 定版做法整理。鏡 15 成品在 MeowHQ「前導影片：影片」鏡 15（2026/11/20 10:59 版），**之後每一鏡都要做到同樣品質**。
> 寫給組員和組員的 AI agent。agent 拿到這份就要能照做，不用回頭問子哲之前的對話。

## 0. 一定要遵守的規則

1. **UI 一律用真實系統錄影**，不讓 AI 畫 UI。AI 只負責人和貓的動作，螢幕在生成時要保持純綠色，之後再換成真實錄影。
2. **生成影片時聲音關掉**。旁白、配樂、字幕都在剪輯時才加（MeowHQ「生成影片前先看」）。成品一律無聲。
3. **人物、場景照定角照與分鏡**。起始畫面只用素材包裡的綠幕底圖，不要自己生新的起始畫面。
4. **畫面上不放字幕或文字**，UI 除外。
5. **成品規格和 MeowHQ 第一、二段一致**：1280x720、16:9、方形像素（SAR 1:1）、30fps、無聲。
6. **秒數以分鏡表為準**（`src/lib/hq/videos/trailer.ts` 或 MeowHQ 卡片上的「成片用 N 秒」）。格數太多就縮，但不能影響說明（見 §2）。
7. **一次做完一整鏡**，做完再給負責人看，不要一格一格問。
8. **點數很少，送出前一定要自己核對**（§4.4）。花點數前先跟發起人確認這一鏡總共要花多少。

## 2. 規劃這一鏡（不花點數）

1. 讀這一鏡的分鏡表：時間、畫面、旁白（`trailer.ts` 的 `no: NN`）。
2. 看 `分鏡計畫圖.png` 和 `格說明/*.txt`，寫下每格在演什麼。
3. **決定格數**：每格大約 2–2.5 秒，再短看不清楚。旁白每一句至少對到一格；跟別格重複、或旁白沒講到的格先拿掉。
   - 例：鏡 15 只有 8 秒，6 格縮成 4 格、每格 2 秒（上傳照片／寫個性／3D 完成／小傑手機）。
4. 每格記下：用哪張綠幕底圖、幾秒、對到哪句旁白、螢幕要放哪段錄影（§3）。
5. **算點數**：要用 AI 生成的格數 × 15 點。把這張表和總點數給發起人確認後，才進 §4。

## 3. 確認系統錄影（不花點數）

1. 這一鏡的錄影：`src/lib/hq/videos/rec-clips.ts`（鏡號 → `rec-*`），檔案在素材包的 `共用/系統錄影/`。
2. **裝置要對**：分鏡畫面是手機，就要手機版錄影；是筆電，就要電腦版錄影。對不上就補錄（下一點）。
3. **錄影裡沒有要的動作就補錄**，例如打字的過程、照片出現的過程、3D 轉一圈。用 `scripts/trailer-rec/rec.mjs` 改一段來錄：手機版加 `{ phone: true }`。只操作、不按儲存，就不會改到正式站資料。補錄做法見 `前導影片/鏡15_生成素材/UI錄影/鏡15_UI片段清單.md` 的 11/20 紀錄。
4. 每格挑一段 2 秒的錄影，記下開始秒數。

> 地雷：錄影的 mp4 存的是**非方形像素**（例如存成 1592x434，實際畫面是 1600x900）。素材包 `共用/系統錄影/` 已經還原過，可以直接用；如果用 MeowHQ 或 `rec.mjs` 剛錄好的檔，`green-composite.sh` 會在合成時還原。不要自己另外縮放，否則 UI 會被壓扁。

## 4. 用 Kling 生成人物動作（花點數）

### 4.1 上傳素材（人做一次）
瀏覽器 agent 不能選電腦裡的檔案，所以由組員把這一鏡要用的綠幕底圖拖進 Kling 畫面中間（或按「Upload」）。之後的步驟都可以交給 agent。

### 4.2 設定（每一支都一樣）
- 模式：**Keyframes**（下方第三個下拉選單，預設是 Omni reference）
- **First frame**：把素材庫裡的綠幕底圖拖進「First frame」格。拖之前先點一下輸入框展開面板，不然面板會收起來、拖不進去。
- 模型：**Kling 2.5 Turbo**（在「More」裡）。Kling 4.0 每支要 50 點，不要用。
- 720p、5s、1 支 → 按鈕顯示 **15 點**。不是 15 就先停下來檢查。
- 免費帳號**一次只能跑一個任務**：前一支還在跑時按生成，會跳出訂閱視窗，關掉等前一支跑完再送。

### 4.3 prompt 範本（英文，照填）

```
Locked-off static camera, no camera movement at all. <誰、在哪、什麼姿勢（照格說明，和首幀一致）>. <1–2 個自然的小動作：手、頭、表情；貓一個小動作>. The <laptop/phone> screen stays a flat, solid, uniform bright green the whole time with nothing on it; the <laptop/phone> does not move and <hands/thumb> never cover the screen. Keep the room, lighting, furniture and the cat's fur pattern exactly as in the first frame. Silent, no text, no subtitles.
```

- 動作要小，2 秒內看得出來就好。大動作會讓螢幕位移，合成會失敗。
- 畫面裡沒有螢幕的格（例如臉部特寫）就刪掉 screen 那一句。

### 4.4 送出前核對（每一支都要）
- [ ] First frame 是這一格的**綠幕**底圖（不是完成分鏡）
- [ ] Kling 2.5 Turbo、720p、5s、1 支、**15 點**
- [ ] prompt 有寫鏡頭固定、螢幕保持綠色、Silent
- [ ] 前一支已經跑完

### 4.5 下載
- 人：在作品上按下載（mp4，有浮水印沒關係，合成會切掉）。
- agent：讀網路請求 `creation-materials`（`mediaType=IMAGE,VIDEO`）的回應，`work.resource.resource` 就是 mp4 網址，用 `curl` 下載。檔名用 `鏡NN-格X_kling25_綠幕_v1.mp4`。

## 5. 驗收 AI 片段（不花點數）

```
node scripts/trailer-board/green-corners.mjs 鏡NN-格X_kling25_綠幕_v1.mp4 1 2
```

- 印出「螢幕穩定，可以合成」→ 記下「建議四角」，進 §6。
- 印出「螢幕不穩」→ 先看畫面：如果只是手指短暫經過螢幕，通常還能用（綠色被擋住的地方會保留手）。如果螢幕不見、變成有內容、或筆電／手機位置大跳，才重生，並在 prompt 加強「does not move」。
- 人和貓要和首幀一致（臉、毛色花紋、衣服），不一致就重生。
- **重生前先跟發起人說**，一次 15 點。

## 6. 合成真實錄影（不花點數）

```
scripts/trailer-board/green-composite.sh <AI片段> 1.0 <錄影.mp4> <錄影開始秒> <desktop|phone> <建議四角> <鏡NN-格X_合成.mp4> 2
```

- `desktop`：筆電螢幕（錄影裁成 16:10）；`phone`：手機螢幕；`desktop-full`：不裁。
- 腳本會還原錄影的真實比例、降一點亮度、加微柔焦、摳綠、去綠邊、裁 16:9、切掉浮水印，輸出 1280x720。
- **抽一格放大檢查**：UI 裡的圓形按鈕要是正圓，字不能扁；螢幕邊緣不能有綠邊；手要在螢幕前面。
  ```
  ffmpeg -ss 1 -i 鏡NN-格X_合成.mp4 -frames:v 1 檢查.png
  ```

## 7. 接成整鏡、上傳

```
scripts/trailer-board/join-shot.sh 鏡NN_整鏡_v1.mp4 格A_合成.mp4 格B_合成.mp4 …
```

- 長度要等於分鏡秒數，規格要是 1280x720、1:1、30fps、無聲。
- 上傳：MeowHQ「前導影片：影片」找到這一鏡的片段卡，按「上傳新版本」。舊版本會保留。
- 鏡 18、20、21、22、24 在後台是「系統錄影」格，**還沒有片段上傳格**。成品先放素材包 `鏡NN/成品/`，等子哲決定上傳位置。

## 9. 鏡 15 的教訓（不要再犯）

- 靜態分鏡圖加推近、只有螢幕在動 → 像投影片，子哲不收。人和貓一定要有動作。
- 直接把錄影貼滿螢幕、不降亮度不柔焦 → 像貼上去的。
- 錄影沒還原真實比例 → UI 被壓扁，子哲會說「比例跑掉」。
- 8 秒塞 6 格 → 太快，看不清楚。
- 錄影用的貓叫 cookie，名字維持 cookie（子哲 11/20 決定）。
- 錄影時 cookie 的 3D 沒有貼圖：用原版 cookie（MeowHQ `cat_20261106_072135`）的成貓貼圖，只在錄影時替換頁面讀到的資料，不寫資料庫（`rec-s15b.mjs` 的 model 段）。
