# bed_single_nora_v01

單人床模型，來源照片 `reference/bed_front.png`（600×600，透明背景，從床尾看的正面微俯視）。

## 規格實測

| 項目 | 要求 | 實際 |
|---|---|---|
| 三角形 | 約 50,000 | 3,696，沒有用到減面 |
| .glb 大小 | 3 MB 以內 | 269 KB，無貼圖 |
| 寬、長 | 1.0 × 2.0 公尺 | 1.0（X）× 2.0（Z） |
| 高 | 約 0.5 公尺 | 床墊頂面 0.43（使用者要求床墊變薄）；床頭板頂端 0.85 |
| 方向 | 床頭朝 -Z | 床頭板在 z = -1 |
| 原點 | 底部中心的地面 | y = 0 為地面 |
| 床底 | 封閉到地面，不要高腳 | 封閉底座，寬 1.0、長 1.95、高 0.2，外緣和床框齊平 |
| 材質 | 只用 MeshStandardMaterial | `main`（床墊，#D4D5D8，粗糙度 0.55）、`trim`（底座、床框、床頭板，#E8E3D8，粗糙度 0.9） |

零件：`plinth` 底座、`frame-rail` 床框、`mattress` 床墊、`headboard` 床頭板。`main` 用在床墊，`trim` 用在底座、床框和床頭板。

## 需要確認的決定

- 床墊厚度由 0.22 改為 0.15，底座 0.2 和床框維持不動，所以床墊頂面從 0.5 降到 0.43。床頭板高度 0.85 是依照片比例推算。
- 只交換了零件使用的材質，`main` 和 `trim` 本身的顏色與粗糙度沒改，所以床墊現在比較光滑（粗糙度 0.55），底座、床框和床頭板比較霧（0.9）。

## 品質關卡

- 輪廓 IoU 0.878（Tier 1），長寬比差 0.017，尺度差 0.059。全幅逐像素重算的 IoU 是 0.861。
- 底座加寬後，用舊相機比對的 IoU 是 0.826，低於門檻 0.85，因為底座填滿了照片兩支床腳之間的空白。比對相機重新擬合後才通過，IoU 的提升來自換相機，不代表模型更像照片。
- 比對時模型高度壓成 0.65 倍，因為照片的床比指定尺寸矮很多。比對相機由透視搜尋擬合（距離 6、相機高 0.6），交付的模型沒有縮放。
- 內部差異 0.143（改動前 0.120）。部分來自刻意的差異：底座是封閉的，床墊和床框的顏色也與照片不同。
- 自相交 0 個頂點；抽樣 8,910／11,088 個頂點，其中 1,617 個無法判定。
- 8 個建模階段全部跑完，轉台、多角度、零件覆蓋和嚴格規格驗證都通過。
- 匯出後的 .glb 與 .ts 渲染 6 個視角沒有可見差異：5 個視角完全相同，俯視最大色差 3（滿分 255）。負向對照（位移 1 公分）有約 7,000 個像素改變。

## 推測的部位

- 床的長度方向、側面床框、床頭板背面和底部：照片只有正面。
- 床頭板厚度 0.05。
- 底座高度：照片是兩支床腳，這裡依指令改成封閉，寬度和長度跟床框一致。

## 與照片的差異

- 寬度比例：照片是雙人床，模型是 1.0 公尺寬的單人床，看起來窄長很多。
- 床腳換成封閉底座，枕頭依指令移除。
- 木紋換成淺灰純色。
- 床單皺褶和包覆邊緣沒有做，床墊是單純的圓角方塊。

## 流程紀錄

- 圓角用 three 的 RoundedBoxGeometry，生成器不支援，數值存在規格的 `roundedBox`，再替換進 .ts。
- 生成器的 MeshPhysicalMaterial 已改寫成 MeshStandardMaterial。
- 材質證據步驟略過，顏色由指令指定。
- optimization 階段的子步驟勾選被檢查清單拒絕（順序問題），關卡都有實際跑過，審查也有記錄。
- .glb 內的 userData 和 uv 已移除。

## 額度

首次製作：5 小時額度從 56% 到 63%（+7%），每週額度從 20% 到 21%（+1%），約 5.7 萬 tokens，包含貓砂調整。

底座加寬與材質交換：5 小時額度從 8% 到 10%（+2%），每週額度從 23% 到 24%（+1%），約 3.8 萬 tokens。

## 修改紀錄

- 床墊變薄時，工作規格裡有一筆把底座加高到 0.27 以維持床墊頂面 0.5 的舊修改，曾一度被寫進交件檔。依使用者要求已還原底座 0.2、床框和床頭板位置，該舊修改仍留在規格的審查歷史中，最新一筆紀錄取代它。
